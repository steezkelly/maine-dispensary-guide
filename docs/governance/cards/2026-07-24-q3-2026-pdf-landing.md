# Q3 2026 PDF — Sub-card 2c: Landing-page capture form

## Objective

Add `/download/maine-cannabis-industry-report-q3-2026` landing page with
the LeadMailtoForm capture form, FAQPage JSON-LD, success card, direct
download link, and all 8 PDF sections summarized. Follows the existing
`compliance-self-assessment.astro` and `first-timer-field-guide.astro`
patterns.

## Author report

This runbook and the focused tests serve as the author handoff. The
landing page ships as a single static Astro page on the existing
Vercel-static / Vercel-rewrite-front pattern.

## What the page does

- Renders the PDF cover and capture form for the Q3 2026 industry report
- Posts to `/api/lead` (Vercel rewrite, added in PR #196), which proxies
  to n8n W13 → mdg_leads. No new operator infrastructure required.
- Falls back to mailto: on any non-2xx (LeadIntakeForm client-side catch).
- Renders FAQPage JSON-LD for SEO/AI-overview eligibility.
- Renders a success card hidden behind `?success=true` (client-side toggle,
  static build can't read query params at build time).
- Renders a direct-download link that bypasses the lead form for operators
  who don't want to subscribe.
- Sets `noindex={false}` so the page is indexable.
- Renders `<AutoRelated />` for downstream internal discovery.
- Sets `publishDate` and `modifiedDate` frontmatter to 2026-07-23.
- Includes a "data cutoff: 23 July 2026" callout so future editions can be
  diffed against this one.
