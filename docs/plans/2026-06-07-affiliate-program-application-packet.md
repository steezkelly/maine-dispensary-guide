## Pitfall 38 reminder

If a brand is NOT in an approved program, do NOT:
- Add a `?aff=` parameter to the brand's URL (this is fake-attribution fraud, not just an FTC issue)
- Use `utm_source=affiliate` tags as a substitute
- Mention the brand in a way that implies endorsement-for-payment

DO:
- Link to the brand's product page as a normal outbound link
- Note in the article that "Maine Dispensary Guide is not currently an affiliate of [Brand]" if the relationship ambiguity is material to the buyer's decision
- Apply to the brand's program if a) the brand has a public program and b) the brand's traffic threshold is realistic given current site traffic
