## FTC compliance — important before any link goes live

When you add `rel="sponsored"` links to any of these partners on MDG:

1. **Page-level disclosure.** Each guide page that includes a sponsored link needs a visible disclosure (e.g., a "Disclosure: Maine Dispensary Guide may earn a commission if you sign up through these links" note near the CTA). Required by FTC Endorsement Guides 16 CFR Part 255.
2. **Site-level disclosure.** MDG already has `/affiliate-disclosure` (confirmed in sitemap). Make sure each partner referral page links to it.
3. **No misleading claims.** You can say "Flowhub is a recommended POS" but not "Flowhub is the best POS" if you have a commercial relationship — that's deceptive. Stick with comparative framing.
4. **`rel="sponsored"` on every outbound partner link.** Already established convention on MDG (the 6 ILGM anchors use it correctly).
